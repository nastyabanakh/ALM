# Медіатека, прев’ю і налаштування сторінок

## Поточна локальна реалізація

- Панель Admin показує секції з поточної сторінки. Вибір поля підсвічує відповідний елемент у прев’ю; подвійний клік по тексту в прев’ю вибирає його поле в панелі. Ширину панелі можна змінювати від 200 px до 50% доступної ширини на широкому екрані.
- Над прев’ю є адреса сторінки та список доступних сторінок. Список будується з маршрутів `src/pages` та опублікованих записів блогу й портфоліо.
- Вкладка Media читає реальні папки та файли з `public/assets`. Можна створити папку, завантажити файл, змінити назву в медіатеці й спільний alt, а також замінити PNG, JPEG, WebP або MP4.
- Медіа без посилань у вихідному коді сайту, опублікованих записах і локальних чернетках показуються з прозорістю 50%. Облік охоплює також шаблонні адреси серій файлів; це підказка редактору, а не підстава для автоматичного видалення файлу.
- Поля зображень і відео в Admin відкривають вибір з Media; текстового вводу шляху для них немає.
- Replace перезаписує файл за тією самою адресою, тому всі локальні використання цієї адреси отримують новий вміст. Перед заміною зберігається локальна резервна копія у `.cms/media-backups`. Зміни медіафайлів і метаданих застосовуються одразу, незалежно від публікації чернетки сторінки.
- Page settings дозволяє задати назву в адмінці, SEO title і description, canonical URL, noindex, Open Graph title/description/image, а також довірений код для `head` і кінця `body`. Ці налаштування входять до чернетки й з’являються на сайті після локальної публікації.

## Межі цього етапу

- Назва у Media є назвою для редактора. Перейменування фізичного файлу та його URL не виконується: це зберігає всі наявні посилання.
- Спільний alt застосовується браузерним скриптом до використань зображення. Для SEO alt потрібно надалі перенести в серверний рендеринг компонентів; до цього HTML, який отримує пошуковий робот без JavaScript, може містити попередній alt.
- Адреса сторінки в Page settings доступна для перегляду. Зміна slug чи батьківського маршруту вимагатиме окремого керування Astro-маршрутами й посиланнями. Захист паролем, налаштування пошуку та RSS тут ще не реалізовані.
- Медіатека й перелік маршрутів працюють у локальному режимі CMS. Віддалене керування ними потребує окремого сховища та публікації медіафайлів.

## Орієнтир Webflow

За основу взято принципи [Assets panel](https://help.webflow.com/hc/en-us/articles/33961269934227-Assets-panel) та [Pages panel](https://help.webflow.com/hc/en-us/articles/33961360067987-Pages-panel-overview): папки, вибір і заміна медіа в усіх використаннях, а також SEO, Open Graph і custom code на рівні сторінки. Тут вони адаптовані до файлового Astro-проєкту.
