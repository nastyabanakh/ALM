# 🧠 Журнал помилок та виправлень (.gemini/LEARNINGS.md)

Цей файл використовується для фіксації уроків, специфіки макетів та коригувань від користувача для уникнення повторних помилок у майбутньому.

## 📌 Загальні правила та спостереження проекту
- **Стек:** Astro SSG (`output: 'static'`).
- **Стилізація:** Fluid REM Scaling (1 px Figma = 1 rem CSS). Zero-px rule.
- **Шрифти:** Тільки self-hosted WOFF2 у `public/assets/fonts/`. Без Google CDN.
- **Box Model:** Тільки атомарні longhand-властивості (`padding-top`, `padding-right`, `padding-bottom`, `padding-left`, `margin-top` тощо).
- **Компоненти:** SFC — стилі виключно всередині блоку `<style>` у відповідному `.astro` файлі.
